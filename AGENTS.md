# Instruccions per a OpenCode

- Prioritza sempre les restriccions estructurals definides a `SPECIFICATION.md`.
- Fase 1: Llegeix l'especificació i genera `test_exemple_consola.py` per poder després validar la correctesa del programa generat.
- Fase 2: Crea el programa `exemple_consola.py` per poder satisfer `test_exemple_consola.py`.
- Bucle d'execució : Executa `python3 test_exemple_consola.py`. Si falla, llegeix els registres del terminal i modifica apropiadament el codi.
- LÍMIT DE SEGURETAT: Si les proves fallen després d'un màxim de **3 bucles de depuració**, ATURA immediatament i espera noves instruccions.
